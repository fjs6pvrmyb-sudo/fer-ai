# FER AI ante Dojo · Demo de tres minutos

Ensayá con Supabase local descartable, Node 24 y `npm ci`. Aplicá `npm run db:reset` y `npm run demo:seed` con las variables de [README](../README.md). Después de compilar una vez, arrancá con `FER_INTELLIGENCE_MODE=demo npm run start -- --hostname 127.0.0.1`. Entrá con la cuenta ficticia que ve ambas empresas y dejá abierto el dashboard de Panadería Demo. El modo demo está rotulado y las cifras provienen de PostgreSQL local.

| Tiempo    | Acción                                                                                                                                                                                                                 | Qué mostrar                                                                                                                                  |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00–0:35 | Abrí **Preparar venta con FER**. Dictá con el teclado del dispositivo o escribí «Vendí un pan de masa madre de cinco mil colones. Me pagaron dos mil por SINPE y quedaron tres mil pendientes». Tocá **Enviar a FER**. | Cantidad 1, catálogo de Panadería, total ₡5.000, cobro ₡2.000 y saldo ₡3.000.                                                                |
| 0:35–1:15 | Elegí **Revisar borrador**, mostrá el resumen y tocá **Confirmar venta** una vez.                                                                                                                                      | Aparece el identificador real de la venta, con acceso a detalle e historial.                                                                 |
| 1:15–1:45 | Entrá a **Ver dashboard**. Usá la jornada de hoy.                                                                                                                                                                      | En una base recién sembrada, muestra ₡5.000 en ventas y ₡2.000 en cobros. Si hubo ensayos previos, mostrá ese incremento.                    |
| 1:45–2:20 | Volvé a **Preparar venta con FER** y preguntá «¿Cuánto vendimos y cuánto cobramos por SINPE hoy?».                                                                                                                     | Empresa, período, ventas y cobros por SINPE, con enlace al dashboard.                                                                        |
| 2:20–3:00 | Elegí **Cambiar empresa → Cafetería Demo → Preparar venta con FER**. Abrí **Ejemplos para esta empresa** y enviá «Vendí 1 Café filtrado».                                                                              | El ejemplo usa el catálogo activo y prepara ₡1.800. La venta anterior y su conversación quedan en Panadería. Dejá el borrador sin confirmar. |

Guardá el texto de la venta para pegarlo si el dictado del dispositivo no está disponible. El navegador recibe texto y FER AI no solicita ni graba audio. Usá solo el mensaje ficticio del guion si el sistema operativo procesa el dictado en línea. Ante una falla del proveedor, podés pasar a **Registrar venta**, seleccionar el mismo producto y registrar el pago mediante la revisión manual. Si la confirmación tarda, comprobá el historial antes de iniciar otra venta.

Para ensayar una corrección sin afectar el guion, prepará una venta sin cobros y enviá «Perdón, eran dos unidades». El borrador cambia y la venta todavía no existe. Cancelalo antes de la demostración. El ensayo automatizado genera capturas de conversación, revisión, resultado, consulta y cambio de empresa en `test-results/`. Ejecutá `npm run test:e2e -- tests/e2e/conversation.spec.ts` con la aplicación compilada, la base local inicializada y el puerto 3000 libre.
